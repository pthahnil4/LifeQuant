一、这是什么

盘感模拟是一套基于 RAG + LLM 的“交易直觉校准器”：把你历史的行情判断、规则、当时可见的行情上下文重建成可检索的“记忆库”，再让 LLM 在这个库的辅助下，对当前局面做一个只记录不下单的“影子预测”，最后通过满窗结算与 A/B 对比告诉你——“这种局面，你的直觉 vs 策略 vs 模型到底谁更靠谱”。

它的定位不是“复读你的感觉”，而是拿你自己的历史命中率当镜子照（探针实测：个人判断远窗口命中低于策略）。

🛡 影子系统铁律：本模块永不下单、永不进入任何委托/风控链路。它只读行情、只写 instinct_* 表。无论预测结果如何，都不影响你的实盘。

二、三层记忆与防泄漏

层内容进预测 prompt？
情景记忆每次决策的“当时可见上下文 + 判断 + 事后对错”仅当时可见信息（事后涨跌一律不注入）
语义记忆蒸馏出的显式规则卡（candidate→active）仅已确认生效且条件命中的规则
工作记忆每次预测的快照/引用/输出/结算流水不进，纯审计与 A/B 统计

防泄漏：“当时可见信息(ctx)”与“事后结果(outcome)”在数据库层面就物理二分。检索相似度、提示词渲染只触碰当时可见信息——防止“用未来数据作弊”。

三、快速上手（四步）

  1. 选币种 → 刷新快照：在下方「📍 当前局面」下拉选一个币 → 点「🔄 刷新快照」（走实盘同源双周期引擎，约几秒），自动列出相似历史案例。
  2. 来一发影子预测：点「⚡ 来一发影子预测」，LLM 会产出一条 pending 预测（看涨/看跌/观望 + 置信度 + 引用了哪些案例/规则）。
  3. 给反馈：在这条预测上点 👍可信/👎存疑、🤝一致/🙅相反——这是判断“元认知校准是否有效”的唯一数据。
  4. 看成绩单：滚到下方「📊 三感对比」看你 vs 策略 vs LLM 的命中率；顶部「📚 Wiki 管理台」可逐条治理规则/审计预测/看校准曲线。

四、五个区块分别干什么

  • 📍 当前局面：选币 + 刷新快照 + 发起预测。
  • 🗂️ 相似历史：随快照自动展示 topK 邻居（仅当时可见信息）。
  • 📜 Wiki 规则卡：快速确认/下线（完整治理在管理台）。candidate 必须人工确认才生效。
  • 🤖 影子预测流水：查看/反馈，“🧮 立即结算到期项”手动触发满窗回填。
  • 📊 三感对比：你 vs 策略 vs LLM 命中率（LLM <60 样本会标注“样本不足”）。

五、关键须知（别当 bug）

① 数据是喂出来的：影子预测想真正上线，需 labeled 样本 ≥100（现在才十几条）。靠你每天照常写“分析记录”、写“复盘四格”、给预测点反馈来积累；源表新增后需隔几天跑一次 corpus_builder --build 同步进语料库。

② 刚生成的预测是 pending：要等近/远窗满（短周期×4 和 ×8）才结算成命中率；bar 未收线会静默重试。

③ 预测报 503：LLM 未配置或未生效（配置进程启动时读取，改完需重启 app）。

④ 三感对比 LLM 列空/“样本不足”：scored 且非 mock 的预测才计数，现在数据少属预期。

六、命令行走狗（可选）

  • 重建/核对语料：python -m crypto.instinct.corpus_builder --build / --verify
  • 检索自检：python -m crypto.instinct.retriever --self-check
  • 统计蒸馏规则：python -m crypto.instinct.wiki_distiller --report
  • 无 key 验管线：python -m crypto.instinct.predict_service --backfill --mock
