# 日记本功能模块说明

> 批次13 · 2026-09-26 落地。页面入口 `/diary`，导航位置「个人管理 → 日记本」。

## 一、功能概览

| 能力 | 口径 |
|---|---|
| 按天记录 | 以 `date`（YYYY-MM-DD）为维度组织，一天可多条，也可一条长记；时间线按天分组倒序展示，支持日历点选某天聚焦查看 |
| 公开/隐私双模式 | 日记本级 `visibility`：`public`=公开可浏览 / `private`=隐私需密码；条目级 `private` 标记：即使在公开模式下，单条隐私日记也需解锁才可见 |
| 密码保护 | 密码只存哈希（argon2 → bcrypt → 标准库 pbkdf2 依次探测，串带算法前缀），库里/日志/导出文件都无明文；解锁态用 HMAC 签名 cookie（2 小时），改/删密码旧 cookie 立即失效 |
| 人生计数器 | 设置出生年月日后实时显示「人生第 N 天」，精确到小时并可细到分钟（前端按基准时间戳本地插值，每秒刷新） |
| 目标倒计时器 | 目标标题 + 截止日期（如「掌握Python技能 / 2026-10-05」），显示剩余天数与小时数，支持完成/编辑/删除，多个并存 |
| 导出/导入 | JSON 文件流导出（不含密码哈希）；导入按条目 id 幂等去重（同 id 跳过），脏条目只跳过不中断 |
| 跨模块关联 | 热量页记录卡新增「去日记本」深链（`/diary?date=…&link=calorie:…`），保存日记自动回指；随笔复盘 `linked_from` 支持 `diary:YYYY-MM-DD` 双向跳转 |

## 三、数据模型

```
diary_settings（单行 id=1）
  visibility     'public' | 'private'
  password_hash  算法前缀哈希串（argon2id$ / bcrypt$ / pbkdf2$）；空=未设置
  birth_date     YYYY-MM-DD；空=未设置

diary_entries（idx_diary_entries_date 按天索引）
  id dentry_xxxxxxxx | date | content | mood | private | linked_from | created_at/updated_at

diary_goals（idx_diary_goals_due）
  id dgoal_xxxxxxxx | title(≤120) | due_date | note | done | 时间列
```

## 四、接口契约（与 journal 模块同款 `{code, message, data}`）

| 方法+路径 | 说明 |
|---|---|
| GET `/diary` | 页面；`?date=YYYY-MM-DD` 定位某日，`?link=calorie:…` 携带关联来源 |
| GET `/diary/api/bootstrap` | 首屏包：settings/unlocked/locked_mode/entries(分页)/has_more/goals/life_age/stats；`date=` 附带当日明细，`before=` 锚点翻页 |
| GET `/diary/api/day?date=` | 某天全部条目 |
| GET `/diary/api/calendar?month=YYYY-MM` | 月格聚合 `{date,total,private}` |
| POST `/diary/api/add` | `{date?,content,mood?,private?,linked_from?}`；关联来源白名单（calorie/journal/plan/expense 前缀） |
| POST `/diary/api/update` / `/delete` | `{id, fields{content?,mood?,private?,date?}}` / `{id}` |
| POST `/diary/api/settings` | `{visibility?, birth_date?}`；无密码不许开 private；生日不许是未来日期 |
| POST `/diary/api/password-set` | `{password, old_password?}`；已有密码必须验旧密；成功后顺带发解锁 cookie |
| POST `/diary/api/password-remove` | `{password}`；清密码同时退回 public 并作废 cookie |
| POST `/diary/api/unlock` / `/lock` | 解锁（发 2h HMAC cookie；同源 10 分钟 10 次失败限流 429）/ 主动上锁 |
| POST `/diary/api/goal-add` / `goal-update` / `goal-delete` | 目标 CRUD；锁定时 401 |
| GET `/diary/api/export` | JSON 文件流；锁定时隐私正文以空串+locked 占位，永不含哈希 |
| POST `/diary/api/import` | `{payload}`；锁定拒导；同 id 幂等跳过 |

### 隐私不变量（服务端唯一事实源）
- 未解锁时隐私条目 `content/mood/created_at` 在**接口层**就被置空并打 `locked` 标记，前端物理拿不到正文；
- `visibility=private` 锁全书：条目、目标、生日、导出正文全部不透出，写接口（含导入）401；
- 解锁 cookie = `HMAC(salt, 密码哈希|过期点).过期点`，不含口令与哈希本身；HttpOnly + SameSite=Lax；
- 未知哈希前缀一律判失败（fail-closed），绝不放行。

## 五、已知边界与后续扩展

- **忘记密码无法找回**（设计上无后门）；清除密码需知原密码。
- 全站仍有 web_auth 访问闸门在前，日记本密码是第二层「书内锁」。
- 交易复盘页跳转日记暂未接线：日记 `linked_from` 已支持 `journal:` 等前缀白名单，扩展 `trade:日期` 只需改 `_safe_linked_from` 一处；随笔侧 `diary:` 引用格式已就绪。
- 心情仅作为文本标记（≤16 字符），无结构化情绪统计。
