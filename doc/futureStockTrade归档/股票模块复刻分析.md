# 股票模块复刻分析报告

## 一、加密币模块 (crypto/) 现有功能

### 1. 页面路由

| 页面 | 路由 | 模板 | 功能描述 |
|------|------|------|----------|
| 监控台 | `/crypto` | `crypto/templates/index.html` | 币种选择、周期选择、综合行情、策略卡片 |
| 策略详情 | `/detail/<symbol>` | `crypto/templates/detail.html` | 行情概览、交易记录、策略统计 |
| 多周期总览 | `/multi-period/<symbol>` | `crypto/templates/multi_period.html` | 多周期卡片、双周期对比分析 |
| API 控制台 | `/api-console` | `crypto/templates/api_console.html` | 市场/账户/资金/交易接口调试 |
| 导航栏 | (全局) | `crypto/templates/nav.html` | 监控台、期货、API 三个导航链接 |

### 2. 后端 API

| API 路由 | 功能 |
|----------|------|
| `/api/strategy/coins` | 获取所有可用币种列表 |
| `/api/strategy/config` (GET/POST) | 获取/保存自选币种配置 |
| `/api/strategy/coin/<symbol>` | 单币种策略数据（支持 bar 参数） |
| `/api/strategy/detail/<symbol>` | 策略详情（支持 bar 参数） |
| `/api/strategy/multi-period/<symbol>` | 多周期方向总览（支持 bars 列表） |
| `/api/market/ticker` | 行情查询 |
| `/api/market/orderbook` | 盘口深度 |
| `/api/market/index_kline` | 指数K线 |
| `/api/market/history_kline` | 历史K线 |
| `/api/market/kline_compare` | K线对比 |
| `/api/account/info` | 账户信息 |
| `/api/account/positions` | 持仓查询 |
| `/api/funds/balance` | 资金余额 |
| `/api/funds/history` | 资金流水 |
| `/api/trade/open_orders` | 当前委托 |
| `/api/trade/order_info` | 订单查询 |
| `/api/trade/history` | 历史委托 |
| `/api/account/max_order_size` | 最大可开仓 |
| `/api/account/interest` | 计息记录 |
| `/api/account/positions_history` | 历史持仓 |
| `/api/account/leverage` | 杠杆倍数 |

### 3. 前端核心功能

- **监控台**: 币种多选 → 保存配置 → 异步加载各币种卡片 → 综合行情判断 → 自动定时刷新
- **策略详情**: 周期选择器(bar切换) → 行情概览12项指标 → 交易记录表 → 7张统计卡片
- **多周期总览**: 7周期方向卡片(3m~1W) → 3组双周期对比(可下拉切换) → 分组定时刷新

## 二、期货模块 (futures/) 现有功能

### 1. 页面路由

| 页面 | 路由 | 模板 | 功能描述 |
|------|------|------|----------|
| 监控台 | `/futures/` | `futures/templates/futures_index.html` | 分类折叠选择、综合行情、策略卡片 |
| 策略详情 | `/futures/detail/<symbol>` | `futures/templates/futures_detail.html` | 含回看周期选择的详情页 |
| 多周期总览 | `/futures/multi/<symbol>` | `futures/templates/futures_multi_period.html` | 6周期卡片+双周期对比(含持仓盈亏) |

### 2. 后端 API

| API 路由 | 功能 |
|----------|------|
| `/futures/api/config` (GET/POST) | 获取/保存自选品种配置 |
| `/futures/api/strategy/data` | 批量获取自选品种策略数据 |
| `/futures/api/strategy/single/<symbol>` | 单品种策略数据 |
| `/futures/api/strategy/detail/<symbol>` | 策略详情（bar + lookback 双参数） |
| `/futures/api/strategy/multi/<symbol>` | 多周期方向总览 |

### 3. 期货模块特色功能

- 分类折叠选择面板（按品类折叠/展开）
- 详情页支持 K线周期(bar) + 回看周期(lookback) 双参数切换
- 多周期卡片每个周期独立显示持仓盈亏
- 基于 Pro3 策略引擎（MACD平滑 + ADX自适应）
- 分钟K线使用真实数据（主力合约解析）

## 三、股票模块 (stocks/) 现有基础

### 已完成的适配层 (`stock_adapter.py`)

| 函数 | 功能 |
|------|------|
| `get_stock_categories()` | 6大行业分类（白酒、金融、科技、新能源、医药、消费） |

| `calculate_stock_single()` | 单只股票分析（MACD+RSI+MA+BOLL） |
| `calculate_stock_strategy_data()` | 批量自选股策略数据 |
| `calculate_stock_multi_period()` | 多周期方向总览（含分钟、日/周线） |
| `get_stock_strategy_detail()` | 股票策略详情 |
| `calculate_stock_pro3_single()` | Pro3单只策略分析 |
| `calculate_stock_pro3_multi_period()` | Pro3多周期方向总览 |
| `get_stock_pro3_strategy_detail()` | Pro3完整策略回测详情 |

### 「__init__.py」已导出的接口

已全部导出上述函数，ready to use。

### 完全缺失的内容

无模板、无蓝图、无前端、未注册到主应用
