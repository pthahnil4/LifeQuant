# 指标导航回测页面说明

> 一个**独立的可视化回测页面**，用于直观对比不同「长周期趋势判断方法」（如 keltner、trix_ma、supertrend 等）对 BOLL（布林带）限价双周期策略信号的影响。
> 页面本身**只读**：零数据库写入、零交易接口触达，所有计算在内存中完成。

---

## 1. 功能定位

策略源文件 `crypto/strategy/trend_strategy_boll_limit_scheduler_like copy 7.py`（下称 **copy 7**）里，
「用哪种长周期趋势方法来判定多空方向」是写在 `TREND_INDICATORS` 注册表中的可选项。
过去只能在命令行里逐个跑、看打印报表，无法直观比较。

**指标导航页**把这件事搬到 Web 上：

- 选一个趋势方法（指标）→ 立刻在 K 线图（蜡烛图）上看到它的买卖点与持仓区间；
- 切换 K 线周期（如 15m / 1H / 4H）→ 自动重算并刷新全部图表；
- 图表下方给出逐笔交易明细与一整套绩效统计；
- 还能一键横向对比注册表里**所有**方法的趋势段特征（反转频率、持续时长等）。

## 3. 页面布局（自上而下三区）

| 区域 | 内容 |
| --- | --- |
| **顶部控制区** | 币种、短周期、长周期、指标、**图表视图**（短周期持仓区间 / 长周期趋势方向段）五个下拉；高级参数（杠杆倍数、ATR 外扩系数、图表 bar 数）；「运行回测」按钮 |
| **中部可视化区** | K 线主图（蜡烛图 + BOLL 上/中/下轨 + 买卖点散点 + 持仓区间底色 + 长周期方向带）；统计卡片；资金曲线图 |
| **底部数据区** | 指标横向对比表；逐笔交易记录表（点击某行可定位到 K 线图对应位置） |

控制区的**周期 / 指标 / 币种**任一切换都会自动触发重跑（无需手动点按钮），满足「切换时自动刷新所有数据和图表」的需求。
**图表视图**切换属于纯前端本地重渲染（同一次回测已同时返回短 / 长两套图表载荷），不重跑回测、不发新请求；但选新指标或调整长周期时，图表会随重跑自动保持当前所选视图。

## 4. 四项核心功能

### 4.1 指标选择器
下拉菜单的数据源来自 `/indicator-nav/api/meta`，实时读取 copy 7 的 `TREND_INDICATORS` 注册表键名。
除原有的 keltner、trix_ma、macd_adx 等方法外，本次为指标导航页**补充了 6 种常见趋势指标**（见 [§6](#6-新增的-6-个趋势指标)）。

### 4.2 交互式图表
- 蜡烛图（candlestick）叠加 BOLL(20,2) 三条轨道线；
- 买入 / 卖出信号用散点（scatter）标注，持仓区间用底色块（markArea）铺出；
- 顶部有一条「长周期方向带」，直观显示多 / 空 / 中性切换；
- 支持短周期 `5m/15m/30m/1H/2H/4H`、长周期 `1H/2H/4H/6H/12H/1D` 档位切换。

#### 4.2.1 短 / 长周期视图切换
控制区的「图表视图」下拉可将主图在两种口径间切换：

- **短周期（默认）**：K 线 = 短周期 bar（如 15m）；底色区间 = 实盘**持仓区间**（触边开仓到平仓）；带买卖点散点标记。
- **长周期**：K 线 = 长周期 bar（如 4H）本身；底色区间 = 趋势指标（keltner / MACD-ADX 等）在长周期数据上直接切出的**多空方向段**（与 `analyze_trend_segments` 同口径）；附长周期 BOLL(20,2) 轨道；**不显示买卖点散点**（因为交易在短周期上发生）。

实现口径：`/api/backtest` 一次回测**同时返回** `chart`（短周期）与 `chart_long`（长周期）两份图表载荷，前端切换仅本地重渲染（无新请求）；回测统计、资金曲线、逐笔交易始织为短周期交易口径，不随视图切换而变。在长周期视图下点击逐笔交易行，会自动切回短周期视图再定位（持仓区间只在短周期口径上有意义）。

### 4.3 交易记录面板
逐笔列出：开 / 平仓时间、开 / 平仓价、盈亏百分比、持仓期间最大盈利 / 最大亏损、持仓时长、是否被剔除、以及该笔之后的定投 / 复投 / 混投资金值。

### 4.4 回测统计概览
关键绩效指标（统计口径逐项对齐 copy 7 的 `PRINT_ORIGINAL_OUTPUT` 报表）：

- **胜率**（win_rate）、**盈亏比**（均值比 final_mean_pl_ratio / 总额比 final_sum_pl_ratio）；
- **定投收益**（fix_money，每笔固定金额）、**复投收益**（contract_money，复利）、**混投收益**（mix_money，1.6 倍阶梯）、**真实定投收益**（fix_real_money，含被剔除单的亏损）；
- **趋势平均持续时间**（来自 segments 的 avg_dur_hours / median_dur_hours）；
- **日均 / 周均盈利**（daily_profit / weekly_profit）；
- **最大回撤率**（fix_drawdown / contract_drawdown / mix_drawdown）。

## 6. 新增的 6 个趋势指标

全部只往 `TREND_INDICATORS` 注册表**追加新键**，不改动 copy 7 上方任何既有方法与默认值，因此不影响原文件稳定性。

| 键名 | 函数 | 参数 | 口径 |
| --- | --- | --- | --- |
| `supertrend` | `_supertrend_direction` | period=10, mult=3.0 | HL2 ± mult×ATR（平均真实波幅）带状轨道，收盘破上带转多、破下带转空，带内保持（标准 SuperTrend 状态机的因果实现） |
| `donchian` | `_donchian_direction` | period=55 | 唐奇安通道突破：收盘创 period 根新高为多、新低为空；通道取 `shift(1)`（上一根为止的极值），避免用当根自身极值自我确认 |
| `ema_cross` | `_ema_cross_direction` | fast=12, slow=26 | 双 EMA（指数移动平均）金叉 / 死叉：快线在慢线上方为多，下方为空 |
| `ma_slope` | `_ma_slope_direction` | period=20, k=5 | 简单均线斜率：SMA(period) 的 k 根差分正负定方向 |
| `linreg` | `_linreg_direction` | period=14 | 线性回归斜率：对最近 period 根收盘做最小二乘拟合，斜率正负定方向 |
| `trix_ma` | `_trix_ma_direction` | period=12, signal=9 | TRIX（三重指数平滑）+ 信号线：TRIX 上穿其 signal 根 EMA 为多、下穿为空（MACD 式用法，与既有 `trix` 的「TRIX 自身差分」口径互补） |

> **注册表优先修正**：`supertrend / donchian / ema_cross / ma_slope / linreg` 这几个名字同时存在于 `COPY4_ONLY`（copy 4 用过、copy 7 刻意不重复的方法名清单）中。
> 修正后 `compute_direction_series` 的判定顺序为：**只要注册表里有就直接用**，仅当注册表与 COPY4_ONLY 两处都没有时才报「copy 4 专属」错误。这样新指标可正常计算，而真正属于 copy 4 专属的键（如 `macd_hist`）口径未放宽、仍会报错。

## 7. HTTP 接口

蓝图 `indicator_nav_bp`，全部为 **GET（只读）**：

| 路由 | 说明 |
| --- | --- |
| `/indicator-nav` | 页面（`active_page='indicator-nav'`） |
| `/indicator-nav/api/meta` | 指标清单 + 短 / 长周期档位（纯内存，不触网不读库） |
| `/indicator-nav/api/compare` | 指标横向对比：注册表全部方法在同一长周期数据上的趋势段统计，按日均反转升序 |
| `/indicator-nav/api/backtest` | 单次回测，参数 `symbol / short_bar / long_bar / indicator / leverage_times / entry_atr_mult / exit_atr_mult / chart_bars / view`（全部可选，有默认值；`view` 取 `short`/`long`，非法值 400） |

**异常映射**：参数非法 → `400`（code=`invalid_param`）；数据 / 依赖故障 → `502`（code=`backtest_error` / `compare_error`）。

`/api/backtest` 返回可直接 jsonify 的 dict，主要字段：
`params / source / notes / indicators / data_range / chart / chart_long / money_curves / trades / stats / segments / elapsed_ms`。
> 无论 `view` 传入何值，响应都同时包含 `chart`（短周期）与 `chart_long`（长周期，长周期 K 线+趋势多空方向段+长周期 BOLL），两者结构一致，前端切换视图免二次请求。

## 8. 数据源双路（CSV 优先 / OKX 回退）

`build_frames(symbol, short_bar, long_bar)` 返回 `(df_short, df_long, source, notes)`：

1. **CSV 优先**（`source='csv'`）：读取 copy 7 的 1 分钟 CSV
   `strategyAI/data/{symbol}_ohlcv_robust_1m_since_2022.csv`，
   用其 `load_symbol_csv` / `_resample_ohlc` 重采样到目标周期 —— 与 copy 7 命令行回测**完全同源**。
2. **OKX 回退**（`source='okx'`）：CSV 不存在时，回退到 OKX 公共行情接口
   （通过 ccxt 库，**无需 API 密钥**，只读 `fetch_ohlcv`），按请求周期直接拉取。
   - 回退拉取跨度 `_OKX_SPAN_DAYS=120` 天，上限 `_OKX_MAX_BARS=12000` 根、`_OKX_MAX_REQUESTS=60` 次；
   - `enableRateLimit` 限速 + 进程内 TTL（存活时间）缓存（`_OKX_TTL_SEC=10 分钟`）+ 串行锁，避免连点打爆公共配额。

> **当前仓库现状**：仓库内**不存在**任何 `*ohlcv*` CSV 文件，因此本机实际运行路径是 **OKX 回退**。
> 前端币种池：`near / btc / eth / sol / xrp / ada / doge / dot / link / ltc`（对齐 `kline_fetcher/symbols.py`）。

**并发保护**：copy 7 模块含 `GLOBAL_DF_1M` 等全局态，所有对其函数的调用都在同一把 `threading.RLock`（可重入锁）内完成，对齐项目「批量接口串行执行规避全局状态竞争」的既有决策。

## 10. 验收与 A/B 对齐结论

冒烟测试：`python -B -m crypto._smoke_indicator_nav`（5 个测试类共 **21 个测试，全部通过**）。
全程零 DB 写入、零 OKX 触达（数据层打桩为进程内合成数据）。

**长周期视图专项断言**（本次新增）：`test_15_chart_long_view_payload` 验证 `chart_long` 各序列与 K 线根数对齐、区间索引合法且同区间方向一致、区间升序不重叠且相邻方向交替，段数与 `analyze_trend_segments` 的 `num_segments` 一致；HTTP 层 `test_22/test_22b/test_23b` 验证默认同时返回 `chart_long`、`view=long` 回显、非法 `view` 参数 400。

**核心验收 —— A/B 对齐**：`indicator_nav_service` 的独立回测引擎与 copy 7 的 backtrader 真引擎
（通过 `_SpyCerebro` 子类截获 `strat.trade_records`，对比的是 copy 7 自己的 `DualTimeframeBollLimitStrategy`，非同源仿制品）
在同一份合成 1m 数据上**逐笔全精度对齐**（开 / 平仓时间、价格、盈亏、最大盈亏、剔除标记完全一致，places=6）：

- 覆盖指标：`keltner / macd_adx / supertrend / trix_ma`；
- 覆盖参数：默认 10 倍杠杆 + 5 倍杠杆 × ATR 外扩（entry_mult=0.3 / exit_mult=0.2）；
- 覆盖档位：`15m/4H` 与 `1H/1D`；
- 资金曲线公式用全精度 raw records 验证定投 / 真实定投终值。

**关键对齐点 —— BOLL 标准差 ddof**：backtrader 的 `StandardDeviation` 用**总体方差** `E[X²]−E[X]²`（ddof=0），
而非 pandas 默认的样本方差（ddof=1）。服务层 `_boll_and_atr` 显式 `std(ddof=0)` 以与引擎对齐
（依据：backtrader `indicators/deviation.py` 源码 `pow(meansquared - squaredmean, 0.5)`）。

### 10.1 真实 OKX 回退数据验证（已通过）

本机无任何 1m CSV，故实际运行路径即 **OKX 公共行情回退**。已在可联网环境用真实数据端到端跑通（`NEAR/USDT:USDT`，近 120 天）：

- **数据加载**：`build_frames('near','1H','4H')` → `source=okx`，短周期 2880 根 / 长周期 720 根（2026-05-30 → 09-27），已补 ADX 列，分页拉取约 11.7s；
- **单指标回测**：`keltner` 产出 55 笔（胜率 78.2%、盈亏比 1.25、定投 1217 / 复投 122381 / 混投 76602、剔除 6 笔），图表 `times/candles/long_dir` 三者长度自洽；
- **新增 6 指标**：`supertrend / donchian / ema_cross / ma_slope / linreg / trix_ma` 均在真实数据上跑通并产出逐笔与统计；
- **横向对比**：`compare_indicators('near','4H')` 覆盖注册表全部 **26 个方法，0 报错**，按日均反转升序正确 —— 最稳 `donchian`(0.033) / `keltner`(0.05)，最不稳 `cmo`(0.633) / `vortex`(0.617)；新增 6 指标全部进入对比。
- **数据新鲜度修复（重要）**：原 `_fetch_okx_frame` 从 `now−120天` 向后翻页、被 `_OKX_MAX_REQUESTS=60`（每页 100 根，共 6000 根）截断，导致 5m/15m 的窗口结束于几十天前（15m 末笔停在约 57 天前、5m 约 99 天前），表现为「K 线数据不新」。已抽纯函数 `_okx_anchor(now_ms, bar_min)` 把窗口锚定为**结束于当前时间**（细周期受请求数上限拉不满 120 天时，优先保「最新」而非「最长」）；真实验证 15m/5m 末根均为当天；并新增零网络回归断言 `test_40_window_ends_at_now`。

> 说明：真实样本仅约 120 天且处于 NEAR 明显上行区间，故胜率/收益偏高，只用于证明**功能与数据链路正确**，不可作为调参依据（口径同 keltner_boll 真实数据 A/B 的既有约定）。
